# Chat Completions API | DeepSeek API Docs

Source: https://api-docs.deepseek.com/api/create-chat-completion

POST `/chat/completions` — Creates a model response for the given chat conversation.

## Request (Body)

- **messages** `object[]` required — list of messages comprising the conversation.
  - System message: `content` string required, `role` string required (`system`), `name` string optional.
  - User message: `content` Text content(string) required, `role` string required (`user`), `name` string optional.
  - Assistant message: `content` string **nullable** required, `role` string required (`assistant`), `name` string optional, `prefix` bool (Beta), `reasoning_content` string nullable (Beta, thinking mode CoT input, requires `prefix:true`).
  - Tool message: `role` string required (`tool`), `content` Text content(string) required, `tool_call_id` string required.
- **model** string required — Possible values: `deepseek-v4-flash`, `deepseek-v4-pro`.
- **thinking** object nullable — controls thinking/non-thinking switch.
  - `type` string: `enabled` | `disabled` (default `enabled`).
  - `reasoning_effort` string: `low` | `high` | `max` (default `high`; `medium`/`xhigh` mapped to `high`).
- **max_tokens** integer nullable.
- **response_format** object nullable — `{type: "json_object"}` for JSON Output; `type` string: `text` | `json_object` (default `text`).
- **stop** object nullable — up to 16 sequences.
- **stream** boolean nullable — SSE streaming, terminated by `data: [DONE]`.
- **stream_options** object nullable — `include_usage` boolean.
- **temperature** number nullable (<=2, default 1).
- **top_p** number nullable (<=1, default 1).
- **tools** `object[]` nullable — currently only functions supported, max 128 functions.
  - `type` string required (`function`).
  - `function` object required: `description` string, `name` string required (a-z A-Z 0-9 _ -, max 64), `parameters` object (JSON Schema; omitting = empty param list), `strict` boolean (default false, Beta).
- **tool_choice** object nullable — `none` | `auto` | `required`, or `{"type":"function","function":{"name":...}}`.
- **logprobs** boolean nullable — whether to return log probabilities.
- **top_logprobs** integer nullable (<=20).
- **user_id** nullable — [a-zA-Z0-9\-_], max 512.
- **frequency_penalty** / **presence_penalty** — **deprecated**, no longer take effect.

## Response 200 (No streaming)

**id** string required — unique identifier for the chat completion.

**choices** `object[]` required:
- **finish_reason** string required — Possible values: `stop`, `length`, `content_filter`, `tool_calls`, `insufficient_system_resource`.
- **index** integer required.
- **message** object required:
  - `content` string **nullable** required.
  - `reasoning_content` string **nullable** — for thinking mode only, reasoning before final answer.
  - `tool_calls` `object[]` — the tool calls generated by the model:
    - `id` string required.
    - `type` string required (`function`).
    - `function` object required: `name` string required, `arguments` string required (JSON format; model may not always generate valid JSON — validate before calling).
  - `role` string required (`assistant`).
- **logprobs** object nullable required:
  - `content` `object[]` nullable required: `token` string, `logprob` number (`-9999.0` = very unlikely), `bytes` integer[] nullable, `top_logprobs` object[] (`token`,`logprob`,`bytes`).
  - `reasoning_content` `object[]` nullable (same token structure).

**created** integer required — Unix timestamp (seconds).

**model** string required — the model used (value is `deepseek-v4-pro`/`deepseek-v4-flash`, NOT `deepseek-chat`).

**system_fingerprint** string required.

**object** string required — Possible values: `chat.completion`.

**usage** object:
- `completion_tokens` integer required.
- `prompt_tokens` integer required (= prompt_cache_hit_tokens + prompt_cache_miss_tokens).
- `prompt_cache_hit_tokens` integer required.
- `prompt_cache_miss_tokens` integer required.
- `total_tokens` integer required.
- `completion_tokens_details` object: `reasoning_tokens` integer.

## Response 200 (Streaming) — `object: chat.completion.chunk`

- **choices** `object[]`: **delta** object (`content` string nullable, `reasoning_content` string nullable, `role` string `assistant`, **logprobs** object nullable with content/reasoning_content), **finish_reason** string nullable (same enum), **index** integer.
- Stream example shows `delta.role` becomes `null` in the final chunk (`{"delta":{"content":"","role":null},"finish_reason":"stop",...}`).

## Notes for type modeling

- `message.tool_calls` EXISTS in Deepseek response.
- `message.reasoning_content` is string|null (present only in thinking mode).
- `logprobs` is an OBJECT `{content:[...], reasoning_content:[...]}`, NOT `null|number[]`.
- `finish_reason` includes `tool_calls` and `insufficient_system_resource`.
- `model` value is e.g. `deepseek-v4-pro`, not `deepseek-chat`.
- Tool call items: `{id, type, function:{name, arguments}}` — no `index` field at JSON level.
